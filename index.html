Project Overview

This system helps a company record transactions, analyze financial behavior, detect financial risk, and provide AI-based suggestions to reduce expenses.

  • User can register income, expense, and miscellaneous records
  • System can auto-categorize uploaded invoice text
  • System can forecast future cashflow
  • System can detect overspending and bankruptcy risk
  • System can provide AI advisory for expense reduction

Main Modules

  • Authentication Module
  • Transaction Management Module
  • OCR & Categorization Module
  • Risk Detection Module
  • Forecast Module
  • AI Advisory Module
